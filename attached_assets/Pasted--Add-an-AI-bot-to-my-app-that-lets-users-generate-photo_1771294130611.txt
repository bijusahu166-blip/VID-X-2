from flask import Flask, request, jsonify
import replicate  # Or Replit's built-in if available

app = Flask(__name__)

@app.route('/generate_image', methods=['POST'])
def generate_image():
    prompt = request.json['prompt']
    # Use Replit-integrated model (or Replicate for Stable Diffusion XL)
    model = replicate.models.get("stability-ai/sdxl")
    output = model.predict(prompt=prompt + " in 4K quality, highly detailed", width=3840, height=2160)
    return jsonify({'image_url': output[0]})

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=8080)

3. Adding AI Video Generation (Game Videos, Anime Clips in 4K)
Video gen is a bit more advanced, but Replit supports it via API integrations like OpenAI's Sora 2 (great for 4K videos) or RunwayML. No keys required if using Replit's unified AI system—it handles auth.
Prompt the Agent:
"Integrate an AI video generator into my app. Users should input a prompt like 'create a 4K anime game trailer of a hero fighting dragons'. Make it generate short videos (10-30s), with options for game-style or anime animation."
What Agent does:
Adds backend code to call video APIs.
Handles input (text prompt, maybe reference image for consistency).
Outputs MP4 in 4K (e.g., 3840x2160 at 30fps).
For "game videos": Prompt for "pixel art game footage" or "3D game animation". For anime: "in Studio Ghibli style" or similar.
Example integration using Sora API (from recent tutorials):
First, Agent might add this to your code:
import openai  # Replit handles the key
from flask import Flask, request, jsonify

app = Flask(__name__)
openai.api_key = 'replit-integrated-key'  # Auto-managed

@app.route('/generate_video', methods=['POST'])
def generate_video():
    prompt = request.json['prompt']
    response = openai.Video.create(
        model="sora-2",
        prompt=prompt + " in 4K resolution, anime style if specified",
        size="3840x2160",
        duration=20  # seconds
    )
    video_url = response['data'][0]['url']
    return jsonify({'video_url': video_url})

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=8080)
